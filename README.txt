Engineer Pay Log — Crew Book Revision Builder Prototype 2

Standalone prototype. It does NOT modify Engineer Pay Log.

This version demonstrates the safer future workflow:
- Transcribe the complete new assignment instead of manually identifying every change.
- Previous verified revision can be displayed read-only for comparison.
- Every regular job has two relief-day fields.
- Each relief day can be covered by Extra Crew or by a specific job number.
- Separate Monday–Friday and Saturday–Sunday base schedules.
- Unlimited day-specific/date-specific exceptions inside either section.
- Job-specific "Notes for review" field for explanations such as:
    "Saturday into Sunday release time"
    "Friday report, release after midnight Saturday"
- General revision notes.
- Dedicated Extra Crew form.
- Dedicated Relief Crew Monday–Sunday table.
- Automatic comparison preview.
- Local browser autosave.
- Export JSON backup.
- Import JSON to resume on another browser/device.

Sample cards in this prototype:
- Regular Crew 277 (revised)
- Regular Crew 203 (added)
- Extra Crew 61
- Relief Crew 474
- Regular Crew 18 (abolished)

For the real builder, the revision cover page would be used to populate all revised/added/abolished crews automatically.
